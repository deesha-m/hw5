# Campus Customs back-office desk (React + Vite + TypeScript)

The dashboard for the Campus Customs agent team. Start the FastAPI backend first (see the main `README.md`), then:

```bash
npm install
npm run dev     # http://localhost:5173, talks to http://localhost:8000
```

Set `VITE_API_URL` in `frontend/.env` to point at a different backend. Design notes are in `../output/design.md`.
